# 03_iha_computation — Irrigated Harvested Area Pipeline

> **Stage 03 of 7** in the HARM crop water-stress pipeline (see the [top-level README](../README.md)). This stage builds the demand-side predictor — where and how much irrigated cropland exists — which tells the model where irrigation actually takes place. Within this stage, the work runs as the sub-stages 0–3 described below.

## Role in the pipeline

Crop water stress (CWS) depends on two things: where and when water is scarce, and where irrigated crop production actually occurs. The climate, vegetation, soil-moisture and water-storage predictors from Stage 01 capture the first; on their own they do not say where irrigated agricultural demand is located. This stage supplies that missing demand-side signal — monthly and annual **irrigated harvested area (IHA)** per crop — which enters the model as the `ha_irrigated` feature.

It produces per-crop IHA on a 5-arcminute reference grid (2160 × 4320) from three external inputs:

- **LUH2** CFT fractions and irrigation fractions (0.25°);
- **CROPGRIDS v1.08** per-crop harvested-area (0.05°);
- **FAOSTAT QCL** country × crop × year harvested-area statistics (used
  as temporal scaling factors).

The outputs feed Stage 04 (`04_dataset_preparation/`): the monthly NCs
supply the `ha_irrigated` feature for the 24 ACEA-resolved crops, and
the annual oac/pec/pdc NCs supply the same feature for the three
aggregate crop categories. Together these 24 resolved crops and 3
aggregate categories make up the study's 27 crop categories.

## Usage

```bash
# One-off download of raw inputs (Stage 0)
python main.py download-data

# Main pipeline (can be run step-by-step or all at once)
python main.py run-pipeline               # Stage 1
python main.py aggregate-oac-pec-pdc      # Stage 2a
python main.py downscale-monthly          # Stage 2b
python main.py validate-vs-spam           # Stage 3

# Or run everything in order
python main.py full-pipeline

# Crop subsets
python main.py run-pipeline      --crops wheat rice maize
python main.py downscale-monthly --crops wh ri1 mai
```

## Reproducing the results without downloading everything

The pipeline outputs (`output/`, `annual/`, `monthly/`) are ~46 GB and
therefore not stored in this repository. To rerun from scratch:

1. Run `python main.py download-data` to fetch LUH2 (Zenodo), CROPGRIDS
   v1.08 (Figshare) and FAOSTAT QCL (FAO API) into `./data/`.
2. Run `python main.py full-pipeline`. On a standard workstation this
   produces the full 1990–2024 dataset in roughly half a day (dominated
   by Stage 1 Method B and Stage 2b monthly downscaling).

SPAM2020 V2r0 (used by Stage 3) must be downloaded separately from the
IFPRI Harvard Dataverse (`10.7910/DVN/SWPENT`) and placed into
`./spam2020_reference/`.

## Notes

- **Stage 1 (Method B)** maps 144 of the 173 CROPGRIDS crops to LUH2
  crop functional types; the 29 excluded crops are listed in
  Supplementary Table S2.1 of the paper. The full crop-by-crop CFT
  assignment is in `src/run_pipeline.py::CFT_MAP`.
- **Stage 2a (aggregate)** is run only for the three aggregate
  categories oac / pec / pdc; the 24 ACEA-resolved crops are taken
  directly from `output/` by Stage 2b.
- **Stage 2b (monthly downscale)** distributes annual HA across
  calendar months proportional to growing-season overlap derived from
  ACEA planting-day / maturity-day NCs; months outside the season get 0.
- **Memory**: the pipeline processes one year at a time with peak RAM
  around 2 GB regardless of the number of years or crops.
